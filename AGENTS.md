# AGENTS.md

## Project overview
sayit: local push-to-talk dictation in Rust. A macOS menu-bar app (AppKit via objc2) with a Linux code path that has never been run. Speech recognition runs on the CPU through ONNX Runtime; the app has no network code.

## Build & test
- Build: `cargo build --release`
- Test: `cargo test`
- Lint: `cargo clippy --all-targets -- -D warnings` (every `unsafe` block needs a `// SAFETY:` comment)
- Dependencies: `cargo audit`
- Run: `./target/release/sayit app -v` (needs a model: `./scripts/fetch-models.sh`)
- App and DMG: `./scripts/package-dmg.sh` (also writes the third-party notices and a `.sha256`)

## Code style
Match the surrounding code: short doc comments that explain *why*, no extra abstraction layers. Platform code stays behind `#[cfg(target_os = "...")]`.

## Boundaries
- Never add HTTP, telemetry or other network access to the binary; downloads go through `scripts/fetch-models.sh`.
- Never write audio or transcripts to disk or logs.
- No new OS permissions or entitlements without a stated reason.
- Don't edit `assets/licenses/` (upstream notices, kept verbatim) or `assets/AppIcon.icns` (generated by `scripts/make-icon.sh`).
- Public text must not mention the maintainer's own machine, real name or file paths.

## Notes
- The ground rules are in CONTRIBUTING.md, and the release steps in RELEASING.md.
- A rebuilt ad-hoc signed `.app` loses its Accessibility permission, so test from a terminal during development.
- Disclose AI help in commits (`Co-Authored-By:`); see AI_POLICY.md.
